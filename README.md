# ذيبان (DHEEB) — الوكيل العام لجلسات Claude Code

يعمل على **مستوى المستخدم** (`~/.claude`) لا داخل مشروع، فيظهر في كل مستودع وكل جلسة جديدة.

## ماذا يفعل فعليًا
| الجزء | الملف | العمل |
|---|---|---|
| سياق البدء | `hooks/dheeb_hook.py session` | يحقن قواعد الاقتصاد والتنسيق في كل جلسة (سطور قليلة). |
| حارس الأدوات | `… pre` | **يمنع** أوامر هدر معروفة (`playwright install`، إعادة تثبيت Claude/Chromium، `cat` لملف ضخم) مع البديل، و**ينصح** عند `grep -r` و`find /`. |
| مراقب الاستهلاك | `… post` | ينبّه عند تكرار الاستدعاء نفسه 3 مرات، ويقرأ استهلاك الجلسة من سجلها كل 25 أداة وينبّه عند تجاوز الحد (يتضاعف الحد بعد كل تنبيه). |
| سجل الاستهلاك | `… stop` | يكتب لقطة لكل جلسة في `~/.dheeb/usage.jsonl`. التقرير: `python3 ~/.dheeb/bin/dheeb_report.py`. |
| الوكيل | `agents/dheeban.md` | وكيل فرعي (نموذج sonnet الأخف) للجرد والتقارير والتنسيق. |
| المهارة | `skills/dheeb` | `/dheeban`: حالة، تقرير، تنسيق مع جلسة أخرى أو كودكس. |
| الذاكرة | `memory/MEMORY.md` | حقائق وقرارات دائمة. |
| التنسيق | `coordination/PROTOCOL.md` | Issues هنا بعناوين `[الوجهة]` + `send_message` بين جلسات Claude السحابية. |

الحدود (`policy.json`، وتُعدَّل في `~/.dheeb/policy.json`): `repeat_warn`، `check_every`، `warn_tokens`، `warn_output`، `big_file_lines`.
الخطاف لا يُسقط جلسة أبدًا: أي خطأ داخلي يُسجَّل في `~/.dheeb/events.jsonl` ويخرج بنجاح.

## كيف يصل إلى كل جلسة
1. **جلسات Claude Code السحابية (الجوال والويب):** سكربت الإعداد لبيئة **Default** = `bootstrap/setup-script.sh`
   (يُولَّد بـ `bash bootstrap/build.sh`). يعمل قبل بدء Claude في كل حاوية جديدة: يثبت من `./agent99` إن كان
   المستودع مرفقًا بالجلسة، وإلا من حزمة مضمّنة من آخر commit. لا يثبت أي حزمة ولا يفشل الإقلاع.
2. **Claude Code على جهاز (اختياري):** `/plugin marketplace add alaoufi/agent99` ثم `/plugin install dheeb@dheeb`،
   أو `git clone` ثم `bash install.sh`. اختر طريقة واحدة كي لا تتكرر الخطافات.

## التحكم من الجوال (بلا لابتوب، بلا اشتراك إضافي)
- افتح تطبيق Claude ← Code ← جلسة جديدة على بيئة Default: ذيبان يعمل تلقائيًا.
- **جلسة القيادة «ذيبان»**: جلسة سحابية دائمة مرفق بها هذا المستودع. اكتب لها من الجوال: «ذيبان: تقرير»،
  «ذيبان: أرسل لجلسة agar …»، «ذيبان: افتح طلبًا لكودكس …». تستخدم `list_sessions`/`send_message`/Issues.
- كل ما يُحفظ يُدفع إلى هذا المستودع، فلا يضيع بانتهاء الحاوية.

## تعديل ذيبان
عدّل ← `bash tests/run.sh` (وحدة + تكامل حقيقي بـ `claude -p`) ← `bash bootstrap/build.sh` ← commit ← حدّث سكربت بيئة Default.

## ما لا يستطيعه (بصراحة)
- لا يرى حد الاستخدام الأسبوعي للحساب؛ يقيس رموز الجلسة الحالية من سجلها فقط.
- السجلات المحلية تزول مع الحاوية؛ الدائم هو هذا المستودع وIssues.
- جلسات كودكس لا تقرأ خطافات Claude؛ تتنسق عبر `AGENTS.md` وIssues هنا.
